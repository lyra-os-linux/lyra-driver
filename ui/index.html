Problemas conhecidos

Casos já vistos no fórum, com a saída recomendada.

  1. No menu do GRUB, abra Start bootloader from a read-only snapshot.
  2. Escolha “antes do driver NVIDIA” e entre normalmente.
  3. Faça o rollback pelo Vega, em Pontos de restauração, e reinicie.

O driver G07 (Turing e mais novas) vem assinado pelo openSUSE e funciona com o Secure Boot ligado. O G06 (Maxwell, Pascal e Volta) registraria a chave no MOK com a senha de root, que é bloqueada no Lyra OS. Por isso o app não instala o G06 com o Secure Boot ligado: desligue-o no firmware antes.

Não há driver NVIDIA para essas placas no Leap 16.1. Elas continuam com o driver livre nouveau, que já vem no sistema.

A placa integrada continua desenhando a área de trabalho, para poupar bateria. Para abrir um app na NVIDIA, clique com o botão direito no ícone e escolha Iniciar usando a placa de vídeo dedicada. Em placas anteriores à Ampere, a instalação liga o gerenciamento de energia dinâmico (NVreg_DynamicPowerManagement=0x02).

Reinstale o driver. Se não resolver, escolha o kernel anterior no GRUB e avise no fórum.
